# 오늘 한 일 영수증

사용자의 그날 Claude 대화를 모아 주요한 일만 추리고, 영수증 한 장(HTML 아티팩트)으로 보여 준다.

## 1. 오늘 대화 모으기

- **지난 대화 검색 도구**(최근 대화 목록, 대화 검색)가 있으면 그것으로 대상 날짜(사용자 현지 시각 기준, 기본은 오늘)에 주고받은 대화를 모두 가져온다. 목록이 잘리면 더 불러와서 그날 것을 빠짐없이 모은다.
- **지금 이 대화**도 그날 한 일이면 포함한다. 단, 영수증을 요청한 부분 자체는 품목에서 뺀다.
- 지난 대화 검색 도구가 없으면 지어내지 말고 이렇게 안내한 뒤 멈춘다:
  "지난 대화를 볼 수 없어서 영수증을 만들 수 없어요. 설정 > 기능에서 이전 대화 검색 및 참조를 켜면 바로 만들 수 있어요. 아니면 오늘 한 일을 몇 줄로 적어 주셔도 돼요."
  사용자가 직접 적어 주면 그 내용으로 만든다.
- 그날 대화가 하나도 없으면 "오늘은 Claude와 나눈 대화가 없어요"라고만 답한다.

## 2. 시간 셈하기

- 대화에 메시지 시각이 보이면, 대화별로 메시지 사이 간격을 더해 **사용시간(분)**을 구한다. 간격이 5분을 넘으면 5분만 센다(자리를 비운 시간으로 본다).
- 시각을 알 수 없으면 시간을 추측하지 않는다. 대신 품목마다 `chats`(그 일에 해당하는 대화 수)를 쓰고 `minutes`는 넣지 않는다. 한 영수증 안에서는 전부 minutes를 쓰거나 전부 chats를 쓴다.

## 3. 품목 추리기 (핵심)

**품목은 일 단위로, 보통 3~10개.** 대화 하나가 품목 하나가 아니다.
- 한 대화 안에서 주제가 바뀌면(기획 → 자료 분석 → 문서 정리) 각각 별도 품목이다.
- 다른 대화에서 같은 일(같은 문서, 같은 자료, 같은 프로젝트)을 이어서 했으면 하나로 합친다.
- 짧은 질문 한두 개로 끝난 잡무(단어 뜻, 간단한 번역, 링크 설명)는 "기타 잡무" 하나로 묶는다. 그것도 아주 작으면 뺀다.
- 결과 없이 끝난 탐색은 "OO 검토"처럼 정직하게 적는다.
- 시간 순서대로 나열한다.

각 품목의 필드:
- **group**: 같은 프로젝트 품목에 붙이는 짧은 이름(8자 안팎, 예: "신제품 캠페인"). 혼자인 품목은 빈 문자열.
- **kind**: 기획, 분석, 문서, 데이터, 조사, 검수, 개발, 소통 중 하나.
- **name**: 12자 안팎 명사구. group 이름은 반복하지 않는다. 좋음 "타깃 정의", "보도자료 초안". 나쁨 "관련 작업", "질문".
- **done**: 25자 안팎 한 줄. 산출물 중심으로, 끝은 짧은 동사. 예 "업종별 반응률 표로 정리". 대화에서 확인되는 사실만 쓴다. 없던 성과를 지어내지 않는다.

**carry_over (내일로 이월)**: 0~3개. 대화가 답 없이 끝났거나 "다음에", "대기", "확인 후" 같은 말이 나온 일만.
**표기**: 가운뎃점(·) 쓰지 않는다. 쉼표나 "와/과"로 푼다.

## 4. 영수증에 넣지 않는 것

비밀번호, API 키, 토큰, URL, 이메일, 전화번호, 계좌, 고객사 내부 금액, 동료 실명(필요하면 "담당자"), 개인 건강이나 가족 같은 사적인 대화 내용. 사적인 대화는 품목에서 아예 뺀다. 영수증은 남에게 보여 줄 수 있는 수준으로만 쓴다.

## 5. 영수증 만들기

1. 이 스킬 폴더의 `assets/receipt-template.html`을 읽는다.
2. `<script type="application/json" id="data">` 안의 JSON만 아래 형식으로 바꾼다. 템플릿의 다른 부분(스타일, 스크립트)은 한 글자도 바꾸지 않는다.
3. 완성된 HTML 전체를 **HTML 아티팩트**로 보여 준다. 제목은 "오늘 한 일 영수증 YYYY-MM-DD".

```json
{
  "date": "2026-10-14",
  "weekday": "수",
  "store": "<상호: 사용자가 알려 준 회사나 팀 이름, 모르면 빈 문자열>",
  "customer": "<고객: 사용자 이름, 모르면 빈 문자열>",
  "issued_at": "<만든 시각 14자리 YYYYMMDDHHMMSS>",
  "payments": ["<이번에 쓴 Claude 모델 이름, 예: Claude Opus 5.5>"],
  "items": [
    {"group": "신제품 캠페인", "kind": "기획", "name": "타깃 정의", "minutes": 25, "done": "핵심 타깃 3개와 메시지 정리"}
  ],
  "carry_over": ["담당자에게 예산 확인"]
}
```

- store, customer는 사용자 정보나 기억에 있으면 쓰고, 없으면 빈 문자열로 둔다(그 줄이 영수증에서 빠진다).
- 아티팩트를 보여 준 뒤에는 짧게 한두 줄만 말한다: 품목 수, 총 사용시간(또는 대화 수), 그리고 "아래 텍스트 복사 버튼으로 메신저에 붙여 넣을 수 있어요".
- store나 customer가 비어 있었다면 끝에 한 줄 덧붙인다: "상호와 이름을 알려 주시면 다음부터 영수증에 넣을게요."
