오늘 한 일 영수증

어디서 쓰세요?

고르면 설치 방법이 영수증으로 나와요. 두 번만 복사해서 보내면, 그다음은 정한 시각마다 알아서 도착해요.

궁금한 점

어떤 영수증이 오나요?

그날 Claude와 한 일을 프로젝트별로 묶고, 일마다 걸린 시간을 적은 영수증이에요. 맨 아래에 총 사용시간과 내일로 넘어간 일이 붙어요.

모비데이즈 AX팀 [ 오늘 한 일 영수증 ] 광고주발굴 4시간 03분 [기획] 기획 재정리 30분 [개발] 네이버 API 첫 수집 ★ 1시간 17분 SF-모비사인 1시간 04분 [검수] 매핑 검수 44분 총 사용시간 5시간 07분

영수증 아래 텍스트 복사를 누르면 Slack에 그대로 붙여 넣을 수 있어요.

내 대화를 읽는다는데 괜찮나요?

읽는 건 내가 이미 Claude와 나눈 대화이고, 읽은 내용은 원래 그 대화를 받았던 Claude에게만 다시 가요. 새로 받는 곳은 없어요.

  1. Claude가 원래 저장해 두는 내 대화 기록을 내 PC 안에서 읽어요.
  2. 비밀번호 같은 민감한 부분은 가리고, 짧게 잘라요.
  3. 그 요약을 Claude가 보고 영수증 품목을 정리해요.
  4. 영수증은 내 PC와 내 계정에만 남아요. 어디로도 자동으로 보내지 않아요.
비밀번호나 개인정보는요?

대화에 붙여 넣은 비밀번호, API 키, 로그인 토큰, 링크, 이메일, 전화번호, 주민번호, 카드번호, 계좌번호는 읽는 단계에서 [가림]으로 바뀌어요. 영수증에는 동료 실명과 금액도 쓰지 않아요.

사용시간은 어떻게 재나요?

Claude와 실제로 주고받은 시간을 더해요.

  • 5분 넘게 아무 대화가 없으면 5분까지만 세요. 자리를 비운 시간은 빠져요.
  • 여러 창을 동시에 띄워 쓴 시간은 한 번만 세요.
비용이나 용량이 드나요?

영수증 한 장에 Claude를 1분 남짓 써요. 내 사용량에서 나가요. 영수증 파일은 하루 15KB 정도라 용량 걱정은 없어요.

안 될 때는요?
  • 자동으로 안 왔어요: 그 시각에 PC나 앱이 꺼져 있었는지 확인해 주세요.
  • "오늘 기록이 없어요"가 떠요: 오늘 한 일을 몇 줄 적어 보내면 그대로 영수증이 돼요.
  • Claude Code에서 "does not support this model"이 보여요: 터미널에서 claude update를 한 번 실행하세요.
그만 쓰고 싶어요
  • 데스크톱 앱: 커스터마이징 › 플러그인에서 daily-receipt를 제거하고, Cowork 예약 작업도 지워요.
  • Claude Code: "영수증 자동 실행 꺼줘"라고 보낸 뒤 claude plugin uninstall daily-receipt를 실행해요.

공식 주소는 github.com/ugjung/daily-receipt 하나뿐이에요. GitHub 계정은 필요 없고, 내 기록만 읽고 밖으로 보내지 않아요. 문의는 AX팀으로.
